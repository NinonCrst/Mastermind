# Mastermind

Le projet a été réalisé en 2022 lors de ma L1 SPI LAS (Sciences Pour l'Ingénieur Licence Accès Santé) en binôme avec Léo Tieng.

Il s'agit d'un jeu Mastermind dont le but est de deviner une combinaison de 5 couleurs (ici des chiffres). Le jeu propose deux modes : joueur contre joueur ou joueur contre IA.
